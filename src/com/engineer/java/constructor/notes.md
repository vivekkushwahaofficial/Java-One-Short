# Java Constructors — Quick Revision

## What is a Constructor?

A constructor is a special class member used to initialize an object.

```java
class Student {

    Student() { // Constructor
        System.out.println("Object created");
    }

    void study() { // Method
        System.out.println("Studying");
    }
}
````

**Rules:**

* Same name as the class.
* No return type, not even `void`.
* Called when an object is created.
* Constructors can be overloaded.

## Constructor vs Method

| Constructor                   | Method                |
| ----------------------------- | --------------------- |
| Same name as class            | Any valid name        |
| No return type                | Has a return type     |
| Called during object creation | Called explicitly     |
| Initializes object            | Performs an operation |

```java
Student s = new Student(); // Calls constructor
s.study();                 // Calls method
```

### String Constructor Example

```java
String original = "Vivek";
String s1 = new String(original);
```

`new String(original)` invokes a **String constructor**.

> This is an example of constructor invocation, not a separate constructor type.

## 1. Default Constructor

Automatically generated by the compiler **only when no constructor is declared**.

```java
class Student {
}

Student s = new Student();
```

## 2. No-Argument Constructor

A constructor written by the programmer with zero parameters.

```java
Student() {
    System.out.println("Created");
}
```

## 3. Parameterized Constructor

Accepts parameters to initialize an object with values.

```java
Student(String name, int age) {
    this.name = name;
    this.age = age;
}

Student s = new Student("Vivek", 22);
```

## 4. Constructor Overloading

Multiple constructors in the same class with different parameter lists.

```java
Student() { }
Student(String name) { }
Student(String name, int age) { }
```

Java selects the constructor using the **number, type, and order** of parameters.

## 5. Constructor Chaining

One constructor calls another constructor of the same class using `this()`.

```java
Student() { }

Student(String name) {
    this();
    this.name = name;
}
```

`this()` must be the **first statement** in the constructor.

## Quick Difference

| Type          | Main idea                                            |
| ------------- | ---------------------------------------------------- |
| Default       | Compiler-generated when no constructor is declared   |
| No-Argument   | Programmer-written constructor with 0 parameters     |
| Parameterized | Constructor with parameters                          |
| Overloading   | Multiple constructors with different parameter lists |
| Chaining      | One constructor calls another using `this()`         |
